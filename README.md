### `./setup.sh`

Trong .env:

- sửa Url tuyệt đối dẫn tới thư mục ảnh lưu trữ trong source Backend
- sửa Url API backend
  Mở gitbash chạy file Setup.sh

### `npm i`

cài đặt các packages và thư viện JavaScript cho một dự án

### `npm start`

Chạy ứng dụng ở chế độ phát triển.  
Mở [http://localhost:3000](http://localhost:3000) để xem trong trình duyệt.
